# BioTrace - Amphibian Species Detection

BioTrace is a friendly mobile app that helps researchers, students, and nature lovers identify amphibians (such as frogs, toads, and salamanders) using environmental DNA (eDNA).

Instead of catching animals in the wild, you can test water or soil samples to see which species live in an area.

---

## What Does This App Do?

- **Identify Amphibians from DNA:** Paste a DNA sequence or upload a file (FASTA or CSV) to see which species it belongs to.
- **Learn About Species:** View photos, common names, and interesting facts about each detected amphibian (powered by iNaturalist and Wikipedia).
- **Scan History:** View past test results and see how confident the match is.
- **Community Projects:** Create or join research projects to collect and share data with others.
- **User Accounts:** Sign up and log in to keep your projects and scans saved.

---

## What It Is Built With

- **Flutter & Dart:** For the clean and simple user interface.
- **Firebase:** For secure user login and data storage.
- **Riverpod:** To keep app data organized and running smoothly.
- **eDNA Prediction API:** To match DNA sequences with amphibian species.

---

## How to Run the App

1. Make sure you have **Flutter** installed on your computer.
2. Open your terminal in this folder:
   ```bash
   flutter pub get
   ```
3. Start the app:
   ```bash
   flutter run
   ```
